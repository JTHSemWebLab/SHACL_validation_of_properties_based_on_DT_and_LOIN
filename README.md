# SHACL_validation_of_properties_based_on_DT_and_LOIN

License: Creative Commons 4.0 - https://creativecommons.org/licenses/by/4.0/

Content: <br/>
shapes turtle file - SHACL shape bank <br/>
requirements turtle file - contains LOIN based requirement set <br/>
assembler script - assembles selected_shapes from the shapes bank based on the chosen requirement set <br/>
selected_shapes - assembled SHACL shapes based on chosen requirement set <br/>
validator script - validates a dataset (example included in repository) against selected_shapes <br/>
example dataset - example for testing <br/>
various schemes - SKOS-schemes for specific properties

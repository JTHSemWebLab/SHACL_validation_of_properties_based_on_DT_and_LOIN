# SHACL_validation_of_properties_based_on_DT_and_LOIN

License: Creative Commons 4.0 - https://creativecommons.org/licenses/by/4.0/

Content:
shapes turtle file - SHACL shape bank
requirements turtle file - contains LOIN based requirement set
assembler script - assembles selected_shapes from the shapes bank based on the chosen requirement set
selected_shapes - assembled SHACL shapes based on chosen requirement set
validator script - validates a dataset (example included in repository) against selected_shapes
example dataset - example for testing
various schemes - SKOS-schemes for specific properties
